# x86-64 Native Backend Specification

## 1. Overview

The x86-64 backend generates 64-bit AMD64/Intel 64 machine instructions without external toolchain dependencies. It implements:

* Full REX prefix, ModR/M, SIB, and displacement calculations.
* Integer arithmetic: `ADD`, `SUB`, `IMUL`, `IDIV`, `CQO`, `NEG`, `NOT`, `AND`, `OR`, `XOR`, `SHL`, `SHR`, `SAR`.
* Comparisons and flags: `CMP`, `TEST`, `SETcc`, `Jcc`, `JMP`.
* Function calls and stack frames: `PUSH`, `POP`, `CALL`, `RET`, 16-byte stack alignment.
* Calling conventions: Windows x64 (RCX, RDX, R8, R9, 32B shadow space) and System V AMD64 (RDI, RSI, RDX, RCX, R8, R9).
* ADOB emission: Generates `.text`, `.rodata` string pool, symbols, relocations (`X86_64_GotPcrel`, `PcRelative32`, `Absolute64`), imports, and exports.

---

## 2. Register Allocation

Physical registers mapped in `X86_64RegisterFile`:
* **General Purpose**: `RAX (0)`, `RCX (1)`, `RDX (2)`, `RBX (3)`, `RSI (6)`, `RDI (7)`, `R8 (8)` through `R15 (15)`.
* **Reserved**: `RSP (4)` (stack pointer), `RBP (5)` (frame pointer).
* **Linear Scan Allocator**: Maps virtual SSA values to physical registers, with automatic stack frame spill slots when register pressure exceeds capacity.
